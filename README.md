# Ermorio.github.io
Voy a explicar el proceso que he seguido para crear una pagina publicada en github.
1. He creado un nuevo repositorio llamado [Ermorio.github.io](ermorio.github.io) con el **README** activado por defecto
2. He ido a mi repositorio [Proyecto_Lenguaje_de_Marcas](ermorio.github.io/Proyecto_Lenguaje_de_Marcas) y en la configuracion **Pages** cambia la configuración de la rama visible de **none** a **main**
